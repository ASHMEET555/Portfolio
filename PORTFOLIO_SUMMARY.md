## 💡 Customization Tips

### Want to Change Something?

**Update Photo:**
- Edit `/src/app/components/HeroSection.tsx` line ~59
- Replace Unsplash URL with your photo

**Add More Projects:**
- Edit `/src/app/components/ProjectsSection.tsx`
- Copy a project object and modify

**Update LinkedIn URL:**
- Edit `/src/app/components/ContactSection.tsx`
- Update the LinkedIn link

**Change Colors:**
- Edit `/src/styles/theme.css`
- Modify `--color-cyberpunk-red` etc.
